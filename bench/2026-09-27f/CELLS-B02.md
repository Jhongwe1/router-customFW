# CELLS-B02 — `R6b-8` 8c-cells, group B: `NET-25` cold boot 2 of 10, into `bench/2026-09-27f`

Written 2026-09-27 (segment 115) under the owner's relaxed process for gate `R6b`. **Not a
PREDICTIONS card**: generated by `tools/gen8c.py B` for this one power cycle and this one
directory, run by `tools/cardrun.py`, guarded by `tools/cardcheck.py commands`. Never edited by
hand; a retry is a new directory and a new card.

## § 1 The image

`r6b8cr`, recipe `527e683b`, quiet `/init` (no interface opened, no `/proc` node written), so
`eth4` is the first interface opened after power; `nfjrom` sha256
`a6c9c818d5cb36fc04f24495c196206406ad3b84212663ae810113b45fbba7e7`.

## § 2 The protocol, as amended

`NET-25`'s registered protocol, with the owner's amendment of 2026-09-26 (*only NB-1* → *NB-1
first*) as `DESIGN.md` § 3 writes it: a cold boot (the board off, the catch opened, the owner's
power-on, the loader caught at its first prompt with the one-space `C-8` line), `looprun`'s
upload and boot, and then **NB-1 as the first command typed at the board**. Between the boot
capture and NB-1 only host cells run. After NB-1: `/proc/interrupts`, the switch page (its
slot-0 column is this power-on's S0′), `asicCounter`; after an NB-1 that did not read 4 of 4,
`port_status`, the ARP table and NB-2. Then `busybox reboot -f` into a catch, so the power-off
finds the board at its prompt.

## § 4 Standing rules

No `FLW`, `EW`, `EB`, non-zero `AUTOBURN` or `FLR`; no loader command but `looprun`'s; every
board cell's `--until` carries the reset banner and is followed by the loader-text gate; a stop
after the catch opens the tail watch at once.
