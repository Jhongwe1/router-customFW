| ⚠️ **Every sha256 recorded for a build belongs to a recipe id and has to be quoted with one.** | `RLXFW_SRC_ID` is a sha256 over `config/` and `kernel/` **as bytes**, comments included, so a typo fix in a declaration produces a different image.
