# docs/log

`LOG.md`'s earlier months, one file per month. Each file holds that month's
entries, moved verbatim out of `LOG.md` and selected by the date in each entry's
heading. They are records and are never edited; a correction is a new dated entry
in [`LOG.md`](../../LOG.md), which holds the current month.
